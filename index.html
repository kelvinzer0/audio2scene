audio2scene — TikTok Viral Sounds Analysis

v0.4.0 · Beat + Onset + Novelty + Intensity → Effect Mapping · 11 songs · 641 segments · 20K+ events

audio2scene detects the structural sections of instrumental music — Intro, Fade In, Main Variation A / B / C / D, Fill In, Break, Ending, and Fade Out — by combining spectral features, beat tracking, and self-similarity matrices. It runs 100% offline on the CPU using librosa + numpy, with no network calls. This dashboard visualizes its output on 11 viral TikTok sounds pulled from archive.org collections — each card below shows the detected structure as an interactive timeline synced to the audio player.

audio2scene v0.4 implements the full AI Video Editor pipeline: FFT/STFT→Spectral Flux→Beat + Onset Detection→Segmentation→Intensity Scoring→Effect Mapping. Each song is analyzed for 8 effect types: Cut, Flash, Zoom, Glitch, Hold, Fade In, Fade Out, Title — ready to import into DaVinci Resolve, Premiere, or ffmpeg.
